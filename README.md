**# InsightFlow AI**



AI-powered data analytics platform for exploring datasets, querying data with AI, and building dashboards.



**## Technology Stack**



\- Python and FastAPI

\- PostgreSQL and SQL

\- LLMs and Text-to-SQL

\- Pandas and Apache Airflow

\- React and TypeScript

\- Power BI

\- Docker and GitHub Actions



**## Project Status**



Initial setup phase. Features will be implemented incrementally.



**## Demo**



A sales dataset will be used to demonstrate analytics and AI-powered querying.
